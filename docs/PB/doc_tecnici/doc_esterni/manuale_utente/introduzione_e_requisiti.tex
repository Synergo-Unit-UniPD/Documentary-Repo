\section{Introduzione}

\subsection{Scopo del documento}
Il presente Manuale Utente è la guida ufficiale all'utilizzo di \textbf{Second Brain}, 
un applicativo sviluppato dal gruppo Synergo Unit. Il documento accompagna l'utente in tutte le fasi: 
dall'avvio del sistema, alla formattazione dei documenti tramite sintassi Markdown, fino all'utilizzo 
avanzato degli strumenti di Intelligenza Artificiale integrati.

\section{Requisiti di Sistema}
Per garantire un'esperienza d'uso fluida e il corretto interfacciamento con i provider LLM, il sistema 
ospite deve soddisfare i seguenti requisti, ovvero, l'utilizzo di un browser tra i seguenti:
\begin{itemize}
    \item Firefox,
    \item Google Chrome e chromium based,
    \item Safari;
\end{itemize}
e l'installazione di docker.

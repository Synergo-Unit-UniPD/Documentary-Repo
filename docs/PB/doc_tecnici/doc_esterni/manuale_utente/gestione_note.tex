\subsection{Gestione dei Documenti}
In alto a destra sono presenti i bottoni relativi alla gestioni dei documenti nonchè 
un indicatore riguardo allo stato del file che stiamo scrivendo il quale può essere verde 
con scritta slavato il che indica che il nostro file non ha alcuna modifica oppure giallo con scritta 
modifiche non salvate il che indica che ci sono delle modifiche da salvare rispetto al file iniziale.

I tre bottoni sono:
\begin{itemize}
    \item Salva che permette il salvataggio del file,
    \item Importa che permette l'importazione nell'applicazione di un file .txt o .md
    \item Esporta che permette l'esportazione del file su cui stiamo lavorando in .pdf .html .json.
\end{itemize}

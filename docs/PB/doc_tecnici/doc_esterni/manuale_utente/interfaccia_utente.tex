\subsection{Modalità di Visualizzazione}
Il sistema offre diverse modalità di Visualizzazione tramite bottoni presenti in alto al centro con i relativi nomi
\begin{itemize}
    \item \textbf{Editor:} Massimizza lo spazio dedicato alla scrittura del codice sorgente Markdown.
    \item \textbf{Render\textsubscript{G}:} Nasconde l'editor per mostrare il documento finale impaginato.
    \item \textbf{Split View\textsubscript{G}:} Mostra a sinistra l'editor e a destra il render aggiornato in tempo reale.
\end{itemize}

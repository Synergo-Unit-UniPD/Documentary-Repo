\subsection*{B}
\begin{itemize}[leftmargin=*]
    \item \textbf{Baseline:} Versione stabile e approvata di un insieme di documenti o artefatti, utilizzata come riferimento per le fasi successive del progetto.
    \item \textbf{Branch:} Linea di sviluppo indipendente all'interno di un repository Git, utilizzata per lavorare su modifiche senza influenzare il ramo principale.
\end{itemize}

% ------------- C -------------
\phantomsection
\addcontentsline{toc}{subsection}{C}
\subsection*{C}
\begin{itemize}[leftmargin=*]
    \item \textbf{Candidatura:} Documento e processo formale con cui il gruppo si propone come fornitore per un capitolato.
    \item \textbf{Ciclo di Vita Documentale:} stati assunti dal documento dal suo concepimento al suo ritiro.
\end{itemize}

\end{itemize}

\begin{itemize}[leftmargin=*]

\subsection*{I}
\begin{itemize}[leftmargin=*]
    \item \textbf{ISO/IEC 12207:1995:} (ISO= International Organization for Standardization) standard generico che non applica un dominio ma permette di capire quali sono i processi che servono per muovere il ciclo di vita, suddivisi in processi primari, di supporto e organizzativi. Fornisce un quadro metodologico per strutturare, gestire e controllare le attività di sviluppo, manutenzione e gestione del software.
    \item \textbf{Issue:} Unità di lavoro o segnalazione registrata su GitHub, utilizzata per tracciare attività, problemi o richieste.
\end{itemize}

\subsection*{P}
\begin{itemize}[leftmargin=*]
    \item \textbf{Pedice G:} Convenzione tipografica utilizzata per indicare che un termine è definito nel glossario.
    \item \textbf{Preventivo dei Costi:} Documento che stima l’impegno economico del progetto sulla base delle ore previste per ciascun ruolo.
    \item \textbf{Pull Request:} Meccanismo GitHub utilizzato per proporre modifiche, richiedere revisione e integrare contributi nel branch principale.
\end{itemize}

% ------------- Q -------------
\phantomsection
\addcontentsline{toc}{subsection}{Q}
\subsection*{Q}
\begin{itemize}[leftmargin=*]
	\item \textbf{OdG preliminare:} Acronimo di “Ordine del Giorno preliminare”. Indica l’elenco iniziale e non definitivo dei punti da trattare nella prossima riunione, utile per preparare materiali, verifiche e attività da discutere.
\end{itemize}

% ------------- R -------------
\phantomsection
\addcontentsline{toc}{subsection}{R}
\subsection*{R}
\begin{itemize}[leftmargin=*]
    \item \textbf{Repository:} Archivio Git che contiene documenti, file e cronologia delle versioni del progetto.
    \item \textbf{Revisione:} Controllo formale di struttura, coerenza e correttezza effettuato da un verificatore.
    \item \textbf{RTB (Requirements and Technology Baseline):} Prima baseline formale del progetto, che fissa requisiti e tecnologie approvate.
    \item \textbf{Ruolo:} Funzione ricoperta da un membro del gruppo nello svolgimento di un’attività.
\end{itemize}

% ------------- S -------------
\phantomsection
\addcontentsline{toc}{subsection}{S}
\subsection*{S}
\begin{itemize}[leftmargin=*]
    \item \textbf{Semantic Versioning:} Convenzione di versionamento basata sul formato \texttt{vX.Y.Z}, dove \texttt{X} indica modifiche maggiori, \texttt{Y} modifiche significative e \texttt{Z} correzioni minori o non semantiche.
    \item \textbf{Struttura documentale:} Organizzazione delle cartelle e dei file all’interno della repository del progetto.
\end{itemize}

% ------------- T -------------
\phantomsection
\addcontentsline{toc}{subsection}{T}
\subsection*{T}
\begin{itemize}[leftmargin=*]
    \item \textbf{Task:} Unità operativa di lavoro assegnata a uno o più membri del gruppo.
    \item \textbf{Title Case:} Convenzione tipografica che prevede l’uso della lettera maiuscola per ogni parola significativa all’interno di un titolo.
    \item \textbf{Template:} Struttura predefinita utilizzata per garantire uniformità.
    \item \textbf{Tempo previsto:} Stima del tempo necessario per completare un’attività.
    \item \textbf{Tempo effettivo:} Tempo realmente impiegato per completare un’attività.
    \item \textbf{T-y.z:} Convenzione per identificare i task nei verbali interni.
\end{itemize}

\subsection*{V}
\begin{itemize}[leftmargin=*]
    \item \textbf{Valutazione dei Capitolati:} Documento che analizza e confronta i capitolati proposti dalle aziende.
    \item \textbf{Verbale Interno:} Documento che riporta discussioni, decisioni e attività pianificate durante una riunione interna.
    \item \textbf{Verbale Esterno:} Documento che riassume gli incontri con il proponente o con il docente.
    \item \textbf{VI-y.x:} Convenzione per identificare le decisioni prese nei verbali interni.
\end{itemize}

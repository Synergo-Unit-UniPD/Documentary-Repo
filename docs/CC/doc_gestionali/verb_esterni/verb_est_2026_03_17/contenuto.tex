% --- 2. CHIARIMENTI TECNICI RICHIESTI ---
\section{Chiarimenti Tecnici Richiesti}
Il gruppo ha richiesto chiarimenti sui seguenti aspetti:
\begin{enumerate}
	\item Modelli LLM e accesso alle API.
	\begin{itemize}
		\item Preferenze sui modelli da utilizzare (tra quelli citati nel capitolato).
		\item Modalità di accesso alle API per modelli non open source.
	\end{itemize}
	\item Valutazione secondo il modello dei “Sei cappelli per pensare”.
	\begin{itemize}
		\item Presenza di linee guida, prompt o criteri specifici.
		\item Possibilità di definire autonomamente l’approccio.
	\end{itemize}
	\item Ambito del Proof of Concept (PoC).
	\begin{itemize}
		\item Priorità tra interazione con LLM e integrazione con editor Markdown.
		\item Livello di completezza richiesto nella prima fase.
	\end{itemize}
	\item Persistenza dei dati.
	\begin{itemize}
		\item Eventuali preferenze su architettura e tecnologie lato server.
		\item Indicazioni sull’uso di database remoto.
	\end{itemize}
	\item Supporto e modalità di interazione con l’azienda.
	\begin{itemize}
		\item Strumenti di comunicazione utilizzati.
		\item Frequenza e modalità degli incontri (remoti o in presenza).
		\item Disponibilità di canali diretti per supporto tecnico.
	\end{itemize}
\end{enumerate}

% --- 3. RESOCONTO ---
\section{Resoconto}
Dalla risposta dell'azienda sono emersi i seguenti punti.

\subsection{Modelli LLM e API}
\begin{itemize}
	\item Verranno fornite chiavi di accesso per i modelli: Gemma, ChatGPT-OSS e Qwen.
	\item L’utilizzo di altri modelli non open source sarà valutato successivamente.
\end{itemize}

\subsection{Sei Cappelli per Pensare}
\begin{itemize}
	\item Non sono fornite linee guida specifiche.
	\item È richiesto di sperimentare autonomamente tramite prompt.
\end{itemize}

\subsection{Ambito del Proof of Concept}
\begin{itemize}
	\item È richiesta sia una prima interazione con gli LLM, ia una prima implementazione dell’editor Markdown.
\end{itemize}

\subsection{Persistenza dei Dati}
\begin{itemize}
	\item Preferenza per database Postgres.
	\item Libertà di scelta lasciata al gruppo.
\end{itemize}

\subsection{Interazione con l'Azienda}
\begin{itemize}
	\item Strumenti: Zoom o Meet.
	\item Possibilità di incontri in presenza (non obbligatori).
	\item Frequenza: almeno due incontri per ciascuna consegna (3 consegne totali).
	\item Maggiore frequenza in caso di difficoltà tecniche.
\end{itemize}

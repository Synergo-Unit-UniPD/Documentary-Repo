# Checklist Revisione Documentazione RTB

## Controlli Generali

### Struttura del documento

* [ ] Presente introduzione
* [ ] Presente scopo del documento
* [ ] Presente glossario
* [ ] Presenti riferimenti normativi
* [ ] Presenti riferimenti informativi
* [ ] Struttura coerente con gli altri documenti
* [ ] Indice corretto
* [ ] Numerazione coerente di sezioni, tabelle e figure

### Qualità redazionale

* [ ] Assenza di errori ortografici
* [ ] Assenza di refusi
* [ ] Linguaggio formale e impersonale
* [ ] Terminologia coerente con il Glossario
* [ ] Nessun riferimento obsoleto
* [ ] Nessun TODO o nota temporanea

### Glossario

* [ ] Prima occorrenza dei termini marcata con pedice G
* [ ] Nessun termine marcato inutilmente
* [ ] Definizioni coerenti con il contesto del progetto
* [ ] Acronimi presenti nel glossario

### Riferimenti

* [ ] Tutti i link funzionano
* [ ] Documenti interni raggiungibili
* [ ] Fonti esterne correttamente citate
* [ ] Riferimenti coerenti con quanto dichiarato nel documento

# Analisi dei Requisiti

* [ ] Attori corretti
* [ ] Attori autenticati/non autenticati coerenti
* [ ] Casi d'uso completi
* [ ] Precondizioni presenti
* [ ] Postcondizioni presenti
* [ ] Scenario principale presente
* [ ] Scenari alternativi presenti ove necessari
* [ ] Tracciamento requisiti → casi d'uso
* [ ] Tracciamento requisiti → fonti
* [ ] Nessun requisito orfano
* [ ] Nessun caso d'uso orfano

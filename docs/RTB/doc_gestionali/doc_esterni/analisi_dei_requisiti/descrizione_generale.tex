\section{Descrizione Generale}

\subsection{Obiettivi del prodotto}
Il prodotto prevede lo sviluppo di un’applicazione per la redazione di testi in Markdown con rendering in tempo reale. L'integrazione di LLM permetterà operazioni di sintesi, riformulazione e valutazione tramite il metodo dei “Sei Cappelli per Pensare”.

\subsection{Funzioni del prodotto}
\begin{itemize}
	\item \textbf{Gestione Editor}: Scrittura e formattazione Markdown;
	\item \textbf{Supporto AI}: Riassunto, traduzione e analisi critica del testo;
	\item \textbf{Gestione File}: Salvataggio ed esportazione locale delle note.
\end{itemize}

\subsection{Caratteristiche degli utenti}
\begin{itemize}
	\item \textbf{Utente}: Utilizzatore che necessita di uno strumento avanzato per la scrittura e l'analisi testuale.
\end{itemize}

\subsection{Vincoli generali}
\begin{itemize}
	\item \textbf{Tecnologici}: Utilizzo di Lucidchart per la modellazione UML standard richiesta.
\end{itemize}

% --- 2. CHIARIMENTI TECNICI RICHIESTI ---
\section{Chiarimenti Richiesti}
Il gruppo ha richiesto chiarimenti sui seguenti aspetti:

\begin{enumerate}
	\item Presentazione Analisi dei requisiti
		\begin{itemize}
			\item presentate tre macroaree e analizzati i diagrammi UML
			\item tracciamento dei requisiti
			\item confronto sui requisiti prestazionali individuati
			\item aggiunto requisito di rendering in tempo reale durante la digitazione
			\item aggiunto requisito per la segnalazione di operazioni con durata superiore ai due secondi
		\end{itemize}
	\item Presentazione Stato dell'arte
		\begin{itemize}
			\item selezionato CodeMirror in quanto Monaco potrebbe risultare più complesso
			\item selezionato Vue
			\item selezionata FastAPI
			\item selezionato PostgreSQL per il supporto a JSON e alle funzionalità embedded tramite plugin
		\end{itemize}
	\item Presentazione proof of concept
		\begin{itemize}
			\item editor aperto su una nota esistente 
				\begin{itemize}
					\item importazione e salvataggio in formato Markdown
					\item applicazione di uno stile per testare una possibile formattazione
					\item visualizzazione in modalità split
					\item interazione con LLM tramite pulsante popup con opzioni di accettazione e rifiuto
						\begin{itemize}
							\item suggerimento diretto su selezione di testo tramite “cappello”
							\item distant writing per interazione con inserimento di prompt
						\end{itemize}
				\end{itemize}
		\end{itemize}
	\item Presentazione mockup
\end{enumerate}
